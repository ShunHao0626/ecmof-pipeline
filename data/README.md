# Dataset notes

`processed/ecmof.json` is a mechanically repaired research snapshot derived from
the original local aggregate. One accidentally nested array was flattened, giving
71 top-level records. No claim is made that every field has been scientifically
verified.

The dataset contains researcher-created structured annotations and bibliographic
references. Publisher PDFs, supplementary files, article figures, and full-text
Markdown are not included.

Before a formal release, the records still need DOI-level deduplication, schema
normalization, field-by-field evidence review, and an explicit data license.
